# Source References

These sources were checked while preparing the expansion. Recheck them during implementation because platform requirements can change.

- WooCommerce developer documentation: current REST/webhook documentation supports product and other resource webhooks, delivery URLs, and signature verification concepts.
- Shopify developer documentation: app webhooks support product and other shop-event subscriptions; App Store distribution requires mandatory compliance webhook subscriptions; HMAC verification and duplicate handling are documented.
- Pinterest developer platform: documents organic content, ads, product catalogs, conversions, and analytics API use cases.
- LinkedIn developer platform and Microsoft Learn: Page Management access is application-reviewed; the Posts API supports creation/retrieval of organic and sponsored posts with permission and version requirements.

Implementation must use official documentation current at the active milestone and must not assume unsupported access.
