# Roadmap Phases and Milestones

## Phase 1 — Foundation

Auth, users, roles, subscriptions, credits, PostgreSQL, upload, assets, basic panels, provider abstraction, audit.

## Phase 2 — Core AI Creation

Text, captions, hashtags, images, video, audio/music, revisions, templates, Brand Profile.

## Phase 3 — Publishing

Facebook, Instagram, TikTok, YouTube, scheduling, drafts, approvals, logs, permissions.

## Phase 4 — AI Marketing Manager

Goal wizard, campaign planner, recommendations, Auto-Pilot, timing engine, variants, explanations, approvals, campaign analytics.

## Phase 5 — Analytics and Optimization

Analytics ingestion, performance history, recommendation engine, best day/hour, comparisons, improvement suggestions.

## Phase 6 — eCommerce Manager

Product import, WooCommerce plugin, Shopify app, product campaigns, offers, abandoned-cart content, commerce analytics and recommendations.

## Phase 7 — Advanced Agents and MCP

MCP registry, agent permissions, approvals, audit, secure connections, marketing/publishing/analytics/eCommerce agents.

## Phase 8 — Scale, Agency, and White Label

Agency accounts, team members, client workspaces, white label, reseller, reporting, API access.

## Sequencing Note

Security, audit, beginner UX, cost metering, and provider abstraction are cross-cutting and begin in Phase 1. Phase 7 expands their agentic use rather than introducing them for the first time.
