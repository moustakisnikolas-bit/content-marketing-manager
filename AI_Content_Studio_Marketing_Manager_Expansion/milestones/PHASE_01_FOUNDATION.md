# Foundation

## Scope

Auth, users, roles, subscriptions, credits, PostgreSQL, file upload, assets, basic panels, provider abstraction, audit, and cross-cutting UX/security.

## Required Deliverables

- approved domain and UX design
- exact schema/migrations
- API and MCP contracts where relevant
- complete implementation files
- unit and PostgreSQL integration tests
- provider/platform/store fakes
- security, privacy, rights, cost, and audit controls
- observability and recovery behavior
- beginner-facing labels and errors
- acceptance checklist

## Exit Gate

The phase is not complete until its active milestone Definition of Done is satisfied, all high-risk paths are policy/audit protected, and a non-technical user can complete the primary journey.
