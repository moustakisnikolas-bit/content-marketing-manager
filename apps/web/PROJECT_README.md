# Web App

Next.js (App Router, TypeScript) client for the user and admin panels. Talks to the backend over REST `/api/v1` only — no business logic here.

Stack: shadcn/ui, Tremor + visx, TanStack Query, Zustand, React Hook Form + Zod, FullCalendar. See `28_OSS_TECHNOLOGY_STACK.md` in the spec pack.
